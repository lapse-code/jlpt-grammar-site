# 连用形 / 词干接口

## 1. 什么时候使用这一类

如果后面的文法点像后缀、复合动词、复合形容词、倾向表达，前面通常用动词ます形去掉 `ます`，或形容词词干，就属于这一类。

典型形式：

```md
動詞ます形去ます + 后项
い形容詞词干 + 后项
な形容詞词干 + 后项
```

例：

```md
起こり得る
起こりかねない
忘れがちだ
食べきる
高そうだ
静かそうだ
```

## 2. 本库中的例子

| 文法 | 接续入口 |
|---|---|
| [[～得る｜可能～]] | 動詞ます形去ます + 得る |
| [[～得ない｜不可能～]] | 動詞ます形去ます + 得ない |
| [[～かねない｜很可能会～；恐怕会～]] | 動詞ます形去ます + かねない |
| [[～かねる｜难以～；不能～]] | 動詞ます形去ます + かねる |
| [[～がち｜容易～；常常～]] | 動詞ます形去ます / 名詞 + がち |
| [[～そうだ・様態｜看起来～；似乎要～]] | Vます形去ます、いA词干、なA词干 + そうだ |

## 3. 识别方法

看到以下后项时，优先检查是不是连用形 / 词干：

```md
得る、得ない、かねる、かねない、がち、がたい、づらい、にくい、やすい、すぎる、きる、ぬく、始める、終わる、そうだ・様態
```

判断重点：

> 前项能不能从 `ます形` 去掉 `ます` 后直接接上？

比如：

```md
起こります → 起こり + 得る
食べます → 食べ + きる
忘れます → 忘れ + がち
```

## 4. 容易混的边界

| 容易混的对象 | 区别 |
|---|---|
| 指定活用接口 | `食べている` 是て形；`食べきる` 是ます形去ます |
| 助动词选择接口 | 样态 `そうだ` 从词干进入，所以本库按连用形 / 词干；但 `べきだ` 不是词干接续，所以不放这里 |
| 助词性接口 | 有些后缀也能接名词，如 `がち`，但主入口仍然是后缀化接续，要看具体文法 |
