# 条件 / 逻辑关系接口

## 1. 什么时候使用这一类

如果文法点的核心不是某个更明确的词类接续、指定活用或助词化表达，而是把前后句绑定成强逻辑关系，就属于这一类。

典型逻辑包括：

- 既然～就～
- 只要～就～
- 在～范围内
- 如果是～另说，但～

## 2. 本库中的例子

| 文法 | 逻辑关系 |
|---|---|
| [[～からには｜既然～就～]] | 前项是既成前提，后项是应有结果 |
| [[～以上は｜既然～就～]] | 前项成立后，后项成为责任或必然判断 |
| [[～上は｜既然～就～]] | 前项是已经决定或实施的行动，后项是责任或觉悟 |
| [[～限り｜只要～；在～范围内]] | 条件或范围 |

## 3. 识别方法

看到这些意义时，要警惕它可能不是普通词类接口：

```md
既然、只要、在……范围内、如果是……另说
```

这类文法点要重点看前后句的逻辑绑定。  
但如果入口已经被 `ない形`、`ば形`、`よう` 系助动词或 `に` 系助词化表达决定，就不要硬放进这一类。

## 4. 容易混的边界

| 容易混的对象 | 区别 |
|---|---|
| 指定活用接口 | [[～ば｜如果～]]、[[～たら｜如果～；一～就～]]、[[～ない限り｜除非～否则不～]]、[[～さえ～ば｜只要～就～]]、[[～ものなら｜如果能～的话；要是～的话]] 有条件意义，但接续形态明确，所以归指定活用 |
| 完整句子 / 引用接口 | [[～としても｜即使～也～；即使作为～也～]] 有让步语义，但主接续是 `普通形／だ＋としても`，前项先作为完整命题被 `と` 接住 |
| 助词性接口 | [[～にしても｜即使～也～；无论～还是～]]、[[～にせよ｜即使～也～]]、[[～にしろ｜即使～也～]] 语义是让步 / 无论，但接续入口是 `に` 系助词化固定表达，所以本库归助词性接口 |
| 助动词选择接口 | [[～ようなら｜如果～的话]]、[[～ようでは｜如果～的话就～]] 有条件意义，但接续入口由 `ようだ` 系规则决定，所以本库归助动词选择接口 |
| 连体修饰接口 | [[～限り｜只要～；在～范围内]] 表面像形式名词，但核心是条件 / 范围逻辑，所以归逻辑类 |
