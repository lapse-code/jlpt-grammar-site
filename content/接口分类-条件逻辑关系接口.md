# 条件 / 逻辑关系接口

## 1. 什么时候使用这一类

如果文法点的核心不是某个词类接续，而是把前后句绑定成强逻辑关系，就属于这一类。

典型逻辑包括：

- 既然～就～
- 即使～也～
- 无论～还是～
- 只要～就～
- 除非～否则～
- 如果能～的话
- 没有～就不能～

## 2. 本库中的例子

| 文法 | 逻辑关系 |
|---|---|
| [[～からには｜既然～就～]] | 前项是既成前提，后项是应有结果 |
| [[～以上は｜既然～就～]] | 前项成立后，后项成为责任或必然判断 |
| [[～としても｜即使～也～；即使作为～也～]] | 让步条件 |
| [[～にしても｜即使～也～；无论～还是～]] | 让步或列举条件 |
| [[～にせよ｜即使～也～]] | 让步条件 |
| [[～限り｜只要～；在～范围内]] | 条件或范围 |
| [[～ものなら｜如果能～的话；要是～的话]] | 假设条件，常带难以实现感 |

## 3. 识别方法

看到这些意义时，要警惕它可能不是普通词类接口：

```md
既然、即使、无论、只要、除非、要是、如果能、没有……就不能
```

这类文法点要重点看前后句的逻辑绑定。

## 4. 容易混的边界

| 容易混的对象 | 区别 |
|---|---|
| 指定活用接口 | [[～ば｜如果～]] 和 [[～たら｜如果～；一～就～]] 有条件意义，但接续形态明确，所以归指定活用 |
| 助词性接口 | [[～にしても｜即使～也～；无论～还是～]] 表面有 `に`，但核心是让步逻辑，所以归逻辑类 |
| 连体修饰接口 | [[～限り｜只要～；在～范围内]] 表面像形式名词，但核心是条件 / 范围逻辑，所以归逻辑类 |
