## 0. 使用方式

这篇按“变形以后还能不能继续活用”来整理。

| 大类 | 判断标准 | 包含内容 |
|---|---|---|
| 生成新动词 | 变形结果还能继续变否定、过去、礼貌、て形 | 可能形、受身形、使役形、使役受身形 |
| 不生成新动词 | 变形结果主要完成接续、语气、条件等功能 | ます形、ない形、ず形、て形、た形、ば形、意向形、命令形、禁止形 |

读表时先看每节开头的“变形结果”。如果写的是“新动词”，后面的否定、时态、礼貌都按新生成的词继续变。

## 1. 动词分类

| 类型 | 日语名称 | 特征 | 例 |
|---|---|---|---|
| 1类动词 | 五段動詞 | 词尾会在 あ・い・う・え・お 段之间移动 | 書く、読む、買う、話す、待つ |
| 2类动词 | 一段動詞 | 多数以 る 结尾，活用时去掉 る | 食べる、見る、起きる、寝る |
| 3类动词 | 不規則動詞 | 单独记忆 | する、来る |

## 2. 活用接口总览

### 2.1 五段动词：五个接口

以 `書く` 为例。

| 接口 | 词尾变化 | 主要用途 | 例 |
|---|---|---|---|
| あ段接口 | 書く → 書か | ない、れる、せる | 書かない、書かれる、書かせる |
| い段接口 | 書く → 書き | ます、たい、ながら、やすい、にくい | 書きます、書きたい |
| う段接口 | 書く | 辞書形、禁止、名词化前 | 書く、書くな、書くこと |
| え段接口 | 書く → 書け | 可能、命令、ば | 書ける、書け、書けば |
| お段接口 | 書く → 書こ | 意向 | 書こう |

特殊注意：

| 项目 | 说明 | 例 |
|---|---|---|
| う结尾动词的あ段 | 不是 あ，而是 わ | 買う → 買わない、買われる、買わせる |
| 行く的て形・た形 | 特殊 | 行く → 行って／行った |

### 2.2 一段动词：去る再接

| 接口 | 规则 | 例 |
|---|---|---|
| 基本规则 | 去る＋后续积木 | 食べる → 食べない／食べます／食べた |
| 可能・受身 | 去る＋られる | 食べる → 食べられる |
| 使役 | 去る＋させる | 食べる → 食べさせる |
| 意向 | 去る＋よう | 食べる → 食べよう |
| 命令 | 去る＋ろ | 食べる → 食べろ |

### 2.3 不规则动词：する・来る

| 原形 | ます | ない | た | て |
|---|---|---|---|---|
| する | します | しない | した | して |
| 来る（くる） | 来ます（きます） | 来ない（こない） | 来た（きた） | 来て（きて） |

## 3. 基础系统：不生成新动词，但有内部变化

### 3.1 ます形：礼貌系统

| 项目 | 内容 |
|---|---|
| 核心意思 | 礼貌表达 |
| 变形结果 | ます系统 |
| 是否生成新动词 | 否 |
| 内部变化 | ます、ません、ました、ませんでした |

#### 生成规则

| 类型 | 规则 | 例 |
|---|---|---|
| 1类・五段 | う段 → い段＋ます | 書く → 書きます、読む → 読みます |
| 2类・一段 | 去る＋ます | 食べる → 食べます、見る → 見ます |
| する | する → します | 勉強する → 勉強します |
| 来る | 来る → 来ます（きます） | 来る → 来ます |

#### ます系统内部变化

| 原动词 | 現在肯定 | 現在否定 | 過去肯定 | 過去否定 |
|---|---|---|---|---|
| 書く | 書きます | 書きません | 書きました | 書きませんでした |
| 読む | 読みます | 読みません | 読みました | 読みませんでした |
| 食べる | 食べます | 食べません | 食べました | 食べませんでした |
| する | します | しません | しました | しませんでした |
| 来る | 来ます（きます） | 来ません（きません） | 来ました（きました） | 来ませんでした（きませんでした） |

### 3.2 ない形：普通否定系统

| 项目 | 内容 |
|---|---|
| 核心意思 | 不做～ |
| 变形结果 | ない系统 |
| 是否生成新动词 | 否 |
| 内部变化 | ない、なかった、なくて、なければ、ないで |

#### 生成规则

| 类型 | 规则 | 例 |
|---|---|---|
| 1类・五段 | う段 → あ段＋ない | 書く → 書かない、読む → 読まない |
| 1类・う结尾 | う → わ＋ない | 買う → 買わない、言う → 言わない |
| 2类・一段 | 去る＋ない | 食べる → 食べない、見る → 見ない |
| する | する → しない | 勉強する → 勉強しない |
| 来る | 来る → 来ない（こない） | 来る → 来ない |

#### ない系统内部变化

| 原动词 | 現在否定 | 過去否定 | て接续 | 条件 | 礼貌禁止 |
|---|---|---|---|---|---|
| 書く | 書かない | 書かなかった | 書かなくて | 書かなければ | 書かないでください |
| 買う | 買わない | 買わなかった | 買わなくて | 買わなければ | 買わないでください |
| 食べる | 食べない | 食べなかった | 食べなくて | 食べなければ | 食べないでください |
| する | しない | しなかった | しなくて | しなければ | しないでください |
| 来る | 来ない（こない） | 来なかった（こなかった） | 来なくて（こなくて） | 来なければ（こなければ） | 来ないでください（こないでください） |

### 3.3 ず形：书面否定・否定接续

| 项目 | 内容 |
|---|---|
| 核心意思 | 不做～；不～而～ |
| 变形结果 | 书面否定・接续形 |
| 是否生成新动词 | 否 |
| 和ない形的关系 | 多数情况下可理解为把 ない 换成 ず，但本质是未然形＋ず |
| 常见形式 | ず、ずに |

#### 生成规则

| 类型 | 规则 | 例 |
|---|---|---|
| 1类・五段 | う段 → あ段＋ず | 書く → 書かず、読む → 読まず |
| 1类・う结尾 | う → わ＋ず | 買う → 買わず、言う → 言わず |
| 2类・一段 | 去る＋ず | 食べる → 食べず、見る → 見ず |
| する | する → せず | 勉強する → 勉強せず |
| 来る | 来る → 来ず（こず） | 来る → 来ず |

#### ない形和ず形对照

| 原动词 | ない形 | ず形 | ずに |
|---|---|---|---|
| 書く | 書かない | 書かず | 書かずに |
| 読む | 読まない | 読まず | 読まずに |
| 買う | 買わない | 買わず | 買わずに |
| 食べる | 食べない | 食べず | 食べずに |
| 見る | 見ない | 見ず | 見ずに |
| する | しない | せず | せずに |
| 来る | 来ない（こない） | 来ず（こず） | 来ずに（こずに） |

#### 常见用法

| 结构 | 意思 | 例 |
|---|---|---|
| Vずに | 不做～就～ | 朝ご飯を食べずに出かけた |
| Vず | 不～而～ | 何も言わず帰った |
| Vずにはいられない | 忍不住～ | 笑わずにはいられない |
| Vざるを得ない | 不得不～ | 行かざるを得ない |

注意：

| 项目 | 说明 |
|---|---|
| 不是所有 ない 都能换 | `ず` 是动词否定，不是形容词否定 |
| する | `しない → せず`，不是 `しず` |
| 语感 | 比 `ないで` 更书面、更硬 |

## 5. 不生成新动词的变形

### 5.1 て形：连接后续语法

| 项目 | 内容 |
|---|---|
| 核心意思 | 连接动作、接补助动词或请求表达 |
| 变形结果 | 接续形 |
| 是否生成新动词 | 否 |
| 否定・礼貌・时态 | て形本身不变；后面的 いる、おく、ください 等变化 |

#### 生成规则

| 类型 | て形 | 例 |
|---|---|---|
| 1类・う / つ / る | って | 買う → 買って、待つ → 待って、帰る → 帰って |
| 1类・む / ぶ / ぬ | んで | 読む → 読んで、遊ぶ → 遊んで、死ぬ → 死んで |
| 1类・く | いて | 書く → 書いて |
| 1类・ぐ | いで | 泳ぐ → 泳いで |
| 1类・す | して | 話す → 話して |
| 例外 | 行って | 行く → 行って |
| 2类・一段 | 去る＋て | 食べる → 食べて |
| する | して | する → して |
| 来る | 来て（きて） | 来る → 来て |

#### 后续常接内容

| 结构 | 意思 | 例 |
|---|---|---|
| ている | 正在～；状态持续 | 書いている |
| てください | 请～ | 書いてください |
| ておく | 事先～；保持～ | 書いておく |
| てしまう | 做完；遗憾地～ | 書いてしまう |
| てもいい | 可以～ | 書いてもいい |
| てはいけない | 不可以～ | 書いてはいけない |

### 5.2 た形：过去、完成、接后续语法

| 项目 | 内容 |
|---|---|
| 核心意思 | 做了～；完成～ |
| 变形结果 | 过去・完成形 |
| 是否生成新动词 | 否 |
| 否定・礼貌・时态 | た形本身不再做完整时态表；否定过去走 ない → なかった |

#### 生成规则

| 类型 | た形 | 例 |
|---|---|---|
| 1类・う / つ / る | った | 買う → 買った、待つ → 待った、帰る → 帰った |
| 1类・む / ぶ / ぬ | んだ | 読む → 読んだ、遊ぶ → 遊んだ、死ぬ → 死んだ |
| 1类・く | いた | 書く → 書いた |
| 1类・ぐ | いだ | 泳ぐ → 泳いだ |
| 1类・す | した | 話す → 話した |
| 例外 | 行った | 行く → 行った |
| 2类・一段 | 去る＋た | 食べる → 食べた |
| する | した | する → した |
| 来る | 来た（きた） | 来る → 来た |

#### 后续常接内容

| 结构 | 意思 | 例 |
|---|---|---|
| たら | 如果～；～之后 | 書いたら |
| たり | 列举动作 | 書いたり読んだりする |
| たことがある | 曾经～过 | 日本へ行ったことがある |
| たばかり | 刚刚～ | 食べたばかり |
| たほうがいい | 最好～ | 早く寝たほうがいい |
| たところだ | 刚刚～ | 今帰ったところだ |

### 5.3 ば形：条件

| 项目 | 内容 |
|---|---|
| 核心意思 | 如果～的话 |
| 变形结果 | 条件形 |
| 是否生成新动词 | 否 |
| 否定 | 用 ない形 → なければ |
| 礼貌・时态 | 一般不做完整礼貌时态表 |

#### 生成规则

| 类型 | 肯定条件 | 否定条件 | 例 |
|---|---|---|---|
| 1类・五段 | う段 → え段＋ば | あ段＋なければ | 書く → 書けば／書かなければ |
| 1类・う结尾 | う → え段＋ば | わ＋なければ | 買う → 買えば／買わなければ |
| 2类・一段 | 去る＋れば | 去る＋なければ | 食べる → 食べれば／食べなければ |
| する | すれば | しなければ | する → すれば／しなければ |
| 来る | 来れば（くれば） | 来なければ（こなければ） | 来る → 来れば／来なければ |

注意：

| 项目 | 说明 | 例 |
|---|---|---|
| ば形 | 偏条件、规则、逻辑关系 | 安ければ買います |
| たら | 偏某情况发生之后 | 日本に着いたら電話します |
