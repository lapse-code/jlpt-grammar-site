## 核心含义

**～いたす** 是 **する** 的自谦语。

中文可以理解为：

- **做～**

- **由我方做～**

- **谨做～**

使用时要抓住三点：

1. 动作主体是说话人自己或己方人员
2. 说话人通过降低己方动作来表示对对方的敬意
3. 它不是用来描写对方动作的尊敬语

比如 **確認いたします** 的重点是“我来确认”，而且把“我方确认”说得郑重谦逊。

它和 **なさる** 是一组必须对比记忆的敬语。

**なさる** 抬高对方动作。

**いたす** 降低我方动作。

中文都可能翻译成“做”，但敬意方向完全相反。

## 接续

> 接口分类：[[N2文法7项接口分类]]：连用形 / 词干接口

基本接续如下：

- サ变名词 + いたす
- 名词 + を + いたす
- 确认する → 確認いたす
- 礼貌形常用 いたします
- 过去形是 いたしました

在实际商务日语中，多见于 **連絡いたします**、**確認いたします**、**案内いたします**。

如果前面使用 お／ご～结构，则变成 **お／ご～いたす**。

如果动作主体是对方，要改用 **なさる** 或 **お／ご～になる**。

如果动作方向是“对方为我方做”，还要考虑 **くださる／いただく**。

## 例句

1. 後ほど連絡いたします。
   - 稍后我联系您。

2. 内容を確認いたしました。
   - 我已经确认了内容。

3. ご案内いたします。
   - 我来为您带路／说明。

4. 失礼いたしました。
   - 失礼了。

## 例句细节解释

1. 後ほど連絡いたします。

   - 这里使用 **～いたす**，是因为联系这个动作由我方完成。
   - **連絡します** 也正确，但商务语气不如 **連絡いたします**。
   - 如果说 **連絡なさいます**，主语就变成对方联系，意思方向不同。
   - 如果说 **ご連絡くださいます**，则是对方联系我方。
   - 所以这个例句要先看动作主体和恩惠方向。

2. 内容を確認いたしました。

   - 这里的确认动作属于我方，适合自谦。
   - **確認しました** 是普通礼貌，**確認いたしました** 更正式。
   - 如果主语是客户，就不能用 **いたしました**。
   - 客户确认应说 **確認なさいました** 或 **ご確認になりました**。
   - 这说明 **いたす** 的核心是降低我方动作。

3. ご案内いたします。

   - 这里使用 **ご案内いたします**，是因为我方为对方提供服务。
   - 它比 **案内いたします** 更像固定接客表达。
   - 如果说 **ご案内なさいます**，那是对方做案内，不符合接客场景。
   - 如果说 **ご案内くださいます**，则是对方为我方带路。
   - 因此要同时看动作主体和动作受益方向。

4. 失礼いたしました。

   - 这是固定化程度很高的自谦表达。
   - **失礼しました** 也可以，但 **失礼いたしました** 更郑重。
   - 它不是说对方失礼，而是我方承认自己的行为造成打扰。
   - 不能把 **いたす** 理解为单纯更礼貌的 **する**，它有我方自谦方向。
   - 所以例句体现的是正式道歉或告辞语气。

## 使用时的核心判断

看到 **～いたす** 时，要按下面顺序判断：

1. 先确认动作主体。
2. 如果动作主体是我方，可以考虑 **いたす**。
3. 如果动作主体是对方，不能用 **いたす**。
4. 对方动作要用 **なさる** 或 **お／ご～になる**。
5. **いたす** 是 **する** 的自谦语。
6. 礼貌形常用 **いたします**。
7. 商务邮件中非常常见。
8. 不要把它当成单纯更高级的 **します**。
9. 它的敬意来自降低我方动作。
10. 若带 お／ご，可能变成 **お／ご～いたします**。
11. 与 **いただく** 不同，它不表示得到对方行为。
12. 核心判断是“谁做”。

最后要确认：这个动作是不是我方为了对方而做。

如果是，用 **～いたす** 很自然。

如果做动作的是对方，就要换成尊敬语。
