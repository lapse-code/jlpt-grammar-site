# 完整句子 / 引用接口

## 1. 什么时候使用这一类

如果后面的文法点需要前面是一个完整命题，或者通过 `と／という／か` 把前面的内容包装起来，就属于这一类。

典型标志：

- と
- という
- か
- かどうか
- とされる
- と考えられる
- ということだ
- というものだ

例：

```md
彼は来月帰国するということだ。
```

`彼は来月帰国する` 是完整句子，后面用 `ということだ` 表示说明或传闻。

## 2. 典型接续

| 前项 | 常见形式 | 例子 |
|---|---|---|
| 動詞 | 普通形 | 来るということだ |
| い形容詞 | 普通形 | 高いということだ |
| な形容詞 | だ / である，按文法决定 | 静かだということだ |
| 名詞 | だ / である，按文法决定 | 学生だということだ |

这类的重点是：

> 前项不是在修饰一个名词，而是作为一个完整判断被引用、说明、评价或疑问化。

## 3. 本库中的例子

| 文法 | 为什么属于这一类 |
|---|---|
| [[～ということだ｜就是说～；听说～]] | `という` 引用前面的完整命题 |
| [[～と考えられる｜可以认为～]] | `と` 把前项作为判断内容 |
| [[～と思われる｜被认为～；看来～]] | `と` 标记被认为的命题 |
| [[～としても｜即使～也～；即使作为～也～]] | `普通形／だ＋としても` 中，前项先作为一个完整命题被 `と` 接住，再表示“即使假定该命题成立” |
| [[～かどうか｜是否～]] | `かどうか` 把前项变成“是否成立”的命题 |
| [[～そうだ・伝聞｜听说～]] | 传闻 `そうだ` 接完整普通形命题，所以按本库归完整句子入口 |

## 4. 识别方法

看到文法点里有：

```md
と、という、か、かどうか
```

先考虑完整句子 / 引用接口。

尤其是名词和な形容词：

```md
学生だと思う
静かだということだ
学生であると考えられる
```

这里不能写成：

```md
× 学生のと思う
× 静かなということだ
```

因为它要的不是“修饰名词”，而是完整判断。

## 5. 容易混的边界

| 容易混的对象 | 区别 |
|---|---|
| 连体修饰 / 形式名词接口 | `来るはずだ` 是修饰 `はず`；`来るということだ` 是引用“来る”这个命题 |
| 助动词选择接口 | [[～かもしれない｜也许～；可能～]] 接完整命题，但它本身是判断助动词性表达，本库归助动词选择接口 |
| 连用形 / 词干接口 | [[～そうだ・様態｜看起来～；似乎要～]] 接词干，不接完整命题，所以不和传闻 `そうだ` 同类 |
| 条件 / 逻辑关系接口 | [[～としても｜即使～也～；即使作为～也～]] 语义是让步条件，但主接续是 `普通形／だ＋としても`，所以按 `と` 系命题入口归本类 |
| 指定活用接口 | [[～ようと思う｜想要～]] 后面有 `と思う`，但前项必须先变成意向形，所以不归本类 |
| 助动词选择接口 | [[～まいと思う｜不打算～]] 后面有 `と思う`，但入口由助动词 `まい` 决定，所以不归本类 |
